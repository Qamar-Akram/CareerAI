# 🚀 CareerAI - AI-Powered Career & Job Platform

CareerAI is a full-stack web application designed to help users manage their careers, analyze resumes, identify skill gaps, and discover suitable job opportunities.

## 🌐 Live Demo

https://career-ai-beige-phi.vercel.app/

## ✨ Features

- 🔐 User Registration & Login
- 📊 Career Dashboard
- 📄 Resume Analyzer
- 🎯 Skill Gap Analysis
- 💼 Job Listings
- 🤖 Smart Job Recommendations
- 💾 Resume & Career Data Persistence
- 🔌 REST API Integration
- 📱 Responsive User Interface
